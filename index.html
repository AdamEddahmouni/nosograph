An open computational platform accelerating drug discovery for Systemic Lupus Erythematosus. Integrating a 72-node knowledge graph (35 genes, 26 drugs, 10 pathways), drug repurposing engine, bioinformatics pipeline, literature mining, and virtual drug screening — all in one place.

Literature Mining Engine

Phase 4 — Complete

Automated PubMed search with 5 broad + 39 per-drug targeted queries. Hybrid biomedical NER (regex + optional spaCy/scispacy) extracts genes, drugs, and pathways. Cross-references findings against repurposing candidates.

🚀 Quick Start

🖥️ Run the full pipeline

# 1. Install dependencies pip install -r requirements.txt # 2. Run everything (one command) python main.py run-all --export-html # 3. Or run individual modules python main.py kg --analyze python main.py repurpose --top 15 --export-html python main.py bioinformatics --export-html python main.py literature --export-html python main.py screening --export-html python main.py trials --export-html python main.py ml --export-html # 4. Run tests python main.py test

🐳 Run with Docker

# Build the image docker compose build # Run the pipeline docker compose run --rm pipeline run-all --export-html # Serve the knowledge graph (visit http://localhost:8080) docker compose up kg-web
