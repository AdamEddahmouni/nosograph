Community experience prototype

A static, read-only sketch of how disease-linked lived-experience posts could be presented alongside — never inside — the evidence model. There is no account system, no submission endpoint, and no storage. Everything on this page is synthetic.

Privacy and consent — read this first

Privacy architecture has not been assessed. This prototype does not collect, transmit, or store anything: it is a static file with no account, no submission endpoint, and no database behind it.

  • Complete anonymity is not claimed or verified. Local file access, browser history, and any hosting layer that served this file would each record metadata that has not been reviewed.
  • There is no consent capture here, because there is nothing to consent to: no text you type is saved or sent, and the only input is a filter control. If the filter controls are used, the choice lives in this tab's memory and disappears on reload.
  • Do not paste personal health information anywhere on this page. It is not designed to receive it and cannot protect it.
  • Real submissions, moderation, reporting, and retention are all unimplemented. Before any public deployment, this surface needs a threat model, a data-retention policy, a moderation duty-of-care plan, and independent privacy review.
