🚀 Quick Start

🖥️ CLI Quick Start

# Run the full pipeline python main.py run-all --export-html # Or run individual modules python main.py kg --analyze python main.py repurpose --top 15 --export-html python main.py bioinformatics --export-html python main.py test

🌐 API Quick Start

# Start the API server python -m med_research.cli serve --host 127.0.0.1 --port 8000 # Or with uvicorn uvicorn med_research.web.main:app --host 127.0.0.1 --port 8000 # Interactive docs at /api/docs
