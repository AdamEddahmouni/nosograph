🖥️ CLI Quick Start

🌐 API Quick Start

# Start the API server python -m med_research.cli serve --host 127.0.0.1 --port 8000 # Or with uvicorn uvicorn med_research.web.main:app --host 127.0.0.1 --port 8000 # Interactive docs at /api/docs
