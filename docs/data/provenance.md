# Data provenance

Provenance answers which source and inputs produced a stored record or result. It supports traceability and reproducibility checks; it does not certify a scientific conclusion. Read the canonical [Provenance](../concepts/provenance.md) page for the semantics and the [source sync lifecycle](../architecture/source-sync-lifecycle.md) for implementation stages.

When reviewing a record, ask:

```text
what source?
which snapshot or version?
what import or transformation?
which stable identifier or fingerprint?
```

Continue to [Data sources](sources.md) for integration maturity and source-specific terms, or [Evidence Explorer](../using/evidence-explorer.md) to inspect a claim locally.
