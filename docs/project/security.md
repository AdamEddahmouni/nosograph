# Security

Use the repository's canonical [SECURITY.md policy](https://github.com/AdamEddahmouni/nosograph/blob/master/SECURITY.md) to report vulnerabilities privately. Do not open a public issue for sensitive details, and do not submit secrets, PHI, or patient-identifiable data.

This page is the single documentation entry point for security reporting. Operational deployment hardening is documented separately in [self-hosted deployment](../deployment.md).
