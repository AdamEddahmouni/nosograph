# NosoGraph v0.1.0 — Public-Alpha Baseline

NosoGraph v0.1.0 is the first deliberately versioned public-alpha baseline for **Disease Intelligence. Connected.**

It preserves the existing disease, claim, evidence, provenance, comparison, and analysis capabilities while establishing an honest pre-1.0 compatibility line before package-index publication or Zenodo archival.

## Highlights

- Responsive GitHub Pages product front door and versioned brand assets.
- Evidence Explorer and provenance-oriented research workflows.
- Canonical public metadata across the package, citation, CodeMeta, README, and documentation.
- Pull-request gates with aggregate Tests and Documentation checks.
- SemVer 0.x policy for public-alpha evolution.

## Compatibility

The canonical CLI remains `nosograph`. The distribution and Python import remain `med-research` and `med_research` during public alpha. A 0.x minor release may include a breaking change only when the changelog contains migration guidance; patch releases remain backward compatible.

The historical v2.1.0–v2.4.0 tags and audit records are preserved as the legacy prototype lineage.

## Maturity

Public Alpha — research use only. NosoGraph is not medical advice, a diagnostic system, or clinical decision support. No public hosted demo is deployed.
