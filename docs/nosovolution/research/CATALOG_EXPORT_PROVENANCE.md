# NosoVolution initiative catalog export

This GitHub file is an **exact 1,457-record export of the fields embedded in the Revision 5 interactive opportunity atlas**, preserving IDs NGX-0001 through NGX-1457. The original authoring CSV contains additional columns not represented in the atlas export (full preconditions, version metadata and some stage fields). To avoid silently misrepresenting the export as that original, this file carries the suffix `_ATLAS_EXPORT.csv`.

The primary machine-readable artifact preserved in this repository is [the interactive atlas](INTERACTIVE_ATLAS_REV5.html), whose embedded JSON is the source for this export. The original 43-column source CSV remains in the 2026-11-21 Revision 5 user archive and can be restored by an authorized local agent with the provided full bundle.

All statuses in this catalog are planning/maturity annotations, not verified software or scientific-completion claims. Some records are concept-only or have incomplete baselines. Do not publish quantitative impacts solely from this list.

Counts: 1,457 unique IDs; 124 named research categories; 100 proposals newly added in Revision 5.
