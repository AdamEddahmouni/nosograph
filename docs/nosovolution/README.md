# NosoVolution — Scientific research expansion and public-launch program

> **Status: approved project name and selected visual direction; research program and brand migration planned.**
> This documentation branch records planning materials and public-launch production briefs. **It does not ship the proposed research ecosystem or change the NosoGraph Python package, CLI, deployed services, or clinical intended use.**

## Start here

NosoVolution is the approved name for the proposed evolution of **NosoGraph**, an open-source biomedical research application. Its ambition is to connect scientific claims, provenance, mathematics, simulations, reproducible experiments, biomedical research methods, and cross-specialty discovery in a modular research environment.

The **existing software** is NosoGraph v0.2.1 Public Alpha, with evidence exploration, traceable claims, local CLI/API workflows, and deterministic comparison of two to five conditions. The NosoVolution program is a **research and engineering roadmap**, not a claim that all future components exist.

### Scope and truthfulness

Scientific claims, benchmarks, numerical models, algorithms, and clinical usefulness need their own independent evaluation. A model running, a test passing, or an agent generating a hypothesis does not establish biological validity. NosoVolution is **research-only**; no diagnostic, treatment, or clinical-decision capability is asserted or authorized by this planning program.

### Compatibility

The repository remains named `nosograph` until a separately reviewed migration. Do not break `med-research`, `med_research`, `nosograph` CLI alias, existing source fingerprints, citations, or user bookmarks merely to apply the brand.

### Contributing to this program

Before implementing any item: inspect local and remote repo divergence, verify licenses and dataset rights, identify a falsifiable scientific question, select a simpler baseline, declare evaluation data and controls, and obtain director approval for repository changes. No paid services, controlled clinical data, patient records, or scientific publication are authorized by this documentation.
