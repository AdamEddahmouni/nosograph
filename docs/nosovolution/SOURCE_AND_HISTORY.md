## Confidence markings

- **Observed in repository** — existing public code or explicitly documented feature.
- **Claimed in historical plan** — a proposal, not code.
- **Generated synthetic example** — a self-contained demo, not biomedical verification.
- **External research/standard** — pin revision and cite authoritative publication.
- **Future vision** — explicitly labeled and never depicted as deployed functionality.
