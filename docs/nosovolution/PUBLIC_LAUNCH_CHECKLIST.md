# Public launch and migration gates

## Blockers before an official NosoVolution platform launch

- [ ] Inspect all authoritative local NosoGraph repositories, drives, worktrees, stashes and unpushed commits against GitHub; preserve divergence.
- [ ] Confirm new brand name rights, company/mascot trademark exposure, domain and social handles.
- [ ] Produce a final manually controlled logo SVG, monochrome small-size treatment and licensed typography.
- [ ] Fix or transparently disclose misleading automatic evidence-quality classifications.
- [ ] Select and independently verify any updated public metrics, versions and download commands.
- [ ] Confirm documentation, license, acknowledgements, contribution policy, code of conduct, security policy and vulnerability disclosure.
- [ ] Verify source/data rights, external imagery rights, music licenses and any user-supplied reference footage exclusion.
- [ ] Capture **real** code/product screenshots for the film; blur secrets and personal information.
- [ ] Render and independently watch the complete video; inspect scene boundaries, legibility, claims and final call to action.
- [ ] Create audio-description, caption and silent-friendly cuts; verify mobile layout.
- [ ] Have a scientific reviewer examine all scientific claims and boundary language.
- [ ] Obtain explicit approval to rename packages/repository, deploy, publish the film or merge the docs branch.

## What the present documentation publication means

Committing the files under `docs/nosovolution/` only makes the **research expansion and planning work** accessible. It is not a v1 release and does not implement, test or launch the future platform.

## Recommended staged release

1. Documentation and concept preview (this branch / PR).
2. Local integration and scientific accuracy correction.
3. Compatible brand migration and clearly labeled beta documentation.
4. Independently reproduced research pilots and external collaborators.
5. Marketing launch after scientific claims, videos and rights are checked.

## Film-specific

- Landscape 1920x1080 master; vertical and 4:5 reframes; 15-second teaser optional.
- Nine-scene, 40-second timing; small source caveats must remain legible.
- No paid credits or autonomous public posting without approval.
- The third-party 40-second visual reference is **not copied into the public repository**.
