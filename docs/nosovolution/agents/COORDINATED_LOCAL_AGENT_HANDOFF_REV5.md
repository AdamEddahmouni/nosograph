## Coordination protocol

Each work item has unique ID and file owner; acquire a time-bounded lease before writing to a shared planning file, and re-check the base hash before merging. Messages are signed by agent identifier and include `task_id`, `commit_sha`, `requested_action`, `evidence_uri`, `tests`, `uncertainty`, `permissions`, `expected_cost`, `rollback`, and `reviewer`. A0 reconciles conflicts and stops duplicate work. Agents may critique in parallel but do not overwrite another lane's artifacts.

`IDEA` vs `EXISTING_CODE` vs `TESTED_CODE` vs `VALIDATED_NUMERICAL_MODEL` vs `EXTERNAL_SCIENTIFIC_EVIDENCE` vs `CLINICAL_RESEARCH` vs `AUTHORIZED_CLINICAL_USE`. No silent promotions.
