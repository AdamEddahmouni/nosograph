# API

FastAPI app title: **NosoGraph API**.

- Swagger UI: `/api/docs`
- OpenAPI JSON: `/openapi.json` (path may be versioned under `/api`)
- Health: `/api/health`

Local development often uses `DEBUG=true`. Production requires `API_KEY` when `DEBUG=false`.

Environment and endpoint catalog: [api-reference.md](../api-reference.md).
