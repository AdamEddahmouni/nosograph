# Evidence Workspace

The full maintained guide is the canonical [Evidence-to-Hypothesis Workspace](../evidence-workspace.md) page. It covers the local CLI and dashboard workflow, asynchronous jobs, dossier fields, provenance, researcher-owned review state, exports, and failure semantics.

This route remains available for existing links. It is not a second competing Workspace guide.

The Workspace is a **Beta** local research workflow. Its rankings are computational prioritization hypotheses, not probabilities of benefit or safety and not treatment recommendations.
